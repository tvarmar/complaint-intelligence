# Complaint Intelligence

A reproducible machine learning project for automatic classification of consumer financial complaints using classical Natural Language Processing (NLP) techniques.

## Project overview

This project explores text classification using historical consumer complaint narratives published by the Consumer Financial Protection Bureau (CFPB).

The project will investigate two classification tasks:

1. **Product classification:** Predict the financial product associated with a complaint.
2. **Issue classification:** Predict the type of issue described in the complaint.

The objective is to build and evaluate reproducible NLP pipelines, compare classical machine learning approaches, investigate class imbalance, and systematically analyze classification errors.

## Planned technologies

- Python
- scikit-learn
- pandas
- TF-IDF
- pytest

## Status

Project initialization. Dataset acquisition, exploratory analysis, model training, and evaluation are pending.

Consumer Financial Protection Bureau (CFPB):

https://www.consumerfinance.gov/foia-requests/foia-electronic-reading-room/cfpb-consumer-complaint-database-narratives-archive/
